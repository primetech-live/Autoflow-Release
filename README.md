# AutoFlow Public Releases

Official public binary distribution repository for **AutoFlow** (`autoflow.primetech.live`).

- **CLI (`v1.0.0`, Free & Open):** Standalone executables for Windows (`x64`), macOS (`arm64` & `x64`), and Linux (`x64`) published as GitHub Release assets under `v1.0.0`.
- **Desktop Studio (Paid / Pro):** Coming Soon.

## Quick Install
- **Windows (PowerShell):** `irm https://autoflow.primetech.live/install.ps1 | iex`
- **macOS / Linux:** `curl -fsSL https://autoflow.primetech.live/install.sh | sh`
